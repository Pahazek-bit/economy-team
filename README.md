# Экономная команда

Открытые универсальные правила для работы ИИ в разных проектах: минимально достаточные роли, короткая передача контекста, разумный выбор моделей и проверка результата.

**Основной файл:** [ECONOMY_TEAM.md](ECONOMY_TEAM.md).

## Использование по ссылке

Отправь агенту сообщение:

> Прочитай https://raw.githubusercontent.com/Pahazek-bit/economy-team/main/ECONOMY_TEAM.md и применяй эти правила к текущей задаче с учётом местных инструкций. Не создавай дополнительных агентов без разрешения. Если ссылка недоступна, сообщи об этом. Затем выполни задачу: [описание задачи].

Доступ к приватным проектам автора не требуется. Если клиент не умеет открывать ссылки, приложи сам ECONOMY_TEAM.md или вставь его текст.

## Применение в проекте

Чтобы правила сохранялись в проекте, поручить агенту добавить ECONOMY_TEAM.md в согласованный каталог и короткую ссылку на него в местный AGENTS.md, сохранив существующие инструкции. Перед изменением агент должен прочитать файлы и проверить Git.

Локальная копия не обновляется автоматически. Обновления проверять отдельно.

## Навык и доступность

В этом репозитории опубликована самостоятельная инструкция. Она **не устанавливается автоматически как навык** в ChatGPT, Codex и другие клиенты. Для установки навыка нужен поддерживаемый конкретным клиентом формат и отдельная проверка установки. Наличие ссылки не доказывает применение правил.

Модели, агенты, инструменты и права зависят от среды. Правила не дают дополнительных квот и не обещают конкретного процента экономии.

## Границы

Не публиковать здесь личные задания, журналы, авторизацию или содержимое закрытых проектов.
